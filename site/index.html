Conversor público

Mapas MindMup versión 3

Convierte mapas MindMup en datos y vistas que puedes reutilizar.

MindMup Conversor transforma un archivo .mup en JSON-CMJN normalizado y en un HTML autocontenido. Conserva la jerarquía, las notas, los atributos y los recursos del mapa fuera de la interfaz de MindMup.

La variante pública no necesita cuenta y ofrece vista previa y descarga del HTML en ZIP. La descarga de JSON está disponible en la variante con inicio de sesión y en el conversor local.

El problema

El árbol de MindMup está pensado para editar, no para consultar.

MindMup organiza las ideas como un árbol anidado. Es una forma natural de construir un mapa, pero la información queda sujeta a esa estructura y a la interfaz de la herramienta.

Entrada

Un árbol cómodo de editar

Cada idea, nota, atributo o enlace ocupa una posición dentro del árbol. El archivo .mup conserva esa organización, pero no ofrece una vista independiente para consultarla.

Límite

Información difícil de reutilizar

Consultar nodos y relaciones, comparar mapas o llevar notas y recursos a otro sistema exige extraer los datos y darles una forma predecible. El árbol original no basta para hacerlo con comodidad.

El resultado es que la información existe, pero queda dentro del árbol y de la interfaz de MindMup. Convertir el mapa a JSON permite extraerla y darle una estructura predecible.

La solución

Una estructura normalizada y una vista lista para abrir.

MindMup Conversor aplana el árbol, separa los datos en colecciones relacionadas y genera un HTML que funciona sin MindMup. El JSON resultante se puede archivar, consultar o integrar en otros sistemas; el HTML se puede abrir y compartir sin la herramienta original.

01

Jerarquía aplanada

Cada idea se convierte en un nodo con parent_id, depth, path y sibling_order. La jerarquía se puede reconstruir y consultar sin recorrer el árbol original.

02

Datos separados

Las notas, los atributos, las pegatinas, los iconos, los enlaces internos y las referencias externas se extraen en colecciones propias.

03

HTML autocontenido

La visualización incluye estilos y scripts en el propio documento. Permite navegar por el árbol, leer notas y consultar recursos sin depender de MindMup.

Diez colecciones, una estructura predecible

El JSON-CMJN reúne la información del mapa en estas colecciones:

  • metadataIdentidad, versión, archivo de origen y número de nodos.
  • nodesNodos aplanados con jerarquía, profundidad, ruta y orden entre hermanos.
  • notesNotas asociadas a los nodos.
  • attributesAtributos y estilos.
  • stickersPegatinas y emojis.
  • iconsIconos, incluidos los incrustados como data:.
  • linksEnlaces internos entre nodos.
  • externalRefsReferencias externas clasificadas.
  • enumsValores enumerados.
  • indexesÍndices precalculados.

Cómo funciona

De un archivo .mup a un resultado utilizable.

El proceso es el mismo en las tres variantes; cambia dónde se ejecuta y qué salida se ofrece.

  1. 1

    Paso 1: Exporta el mapa

    Guarda el mapa desde MindMup versión 3 como archivo .mup. Las variantes web validan la extensión, el tamaño, el JSON y los campos obligatorios; el conversor local valida el JSON y los campos.

  2. 2

    Paso 2: Convierte la estructura

    Ocho capas leen el mapa, aplanan el árbol, extraen notas, separan atributos, convierten pegatinas, clasifican referencias, ensamblan las colecciones y guardan el resultado.

  3. 3

    Paso 3: Obtén el JSON-CMJN

    El resultado es un JSON normalizado con diez colecciones. Incluye la jerarquía de nodos, las notas, los atributos, los recursos y los índices calculados.

  4. 4

    Paso 4: Abre o descarga el resultado

    El visualizador construye un HTML autocontenido. La variante pública lo ofrece para previsualizar y descargar en ZIP; la variante con inicio de sesión añade la descarga de JSON; el conversor local escribe el JSON y, con la opción correspondiente, el HTML en una carpeta.

El HTML incluye navegación por el árbol, contador de nodos visibles, expansión y contracción, cambio de tema, notas, pegatinas, iconos, referencias, enlaces, adjuntos, índice y ruta de navegación.

Tres formas de uso

Elige la variante que encaja con tu caso.

Las dos variantes web comparten el mismo código; la configuración decide el modo. El conversor local funciona sin Cloudflare.

Consultar el uso local

Una diferencia importante: la variante pública usa R2 para objetos temporales y no ofrece catálogo ni descarga de JSON. La variante con inicio de sesión conserva los resultados en R2 y permite descargar el JSON. El conversor local escribe en la carpeta que indiques.
